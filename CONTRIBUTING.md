# Contributing to the Sales jobs list

Help sales professionals find openings across prospecting, account work, and leadership. Include the employer's own posting so readers can check the role.

## What belongs in this list

Sales development, account executive, account management, sales operations, and sales leadership roles belong here.

## Suggest a job

Include the exact role title, employer's own apply link, and any stated territory or sales focus.

[Open the Add a job form](https://github.com/Jobhacki/sales-jobs/issues/new?template=add-a-job.yml)

## Report a dead link

Include the sales role title, employer, link, and what the posting says when opened.

[Open the Report a dead link form](https://github.com/Jobhacki/sales-jobs/issues/new?template=report-a-dead-link.yml)

## Ground rules

- Use the issue forms above. The table in the README is generated, so a pull request that edits it will be overwritten on the next refresh.
- Links must go to the employer's own career page or hiring system. Links to job aggregators and links with tracking or session parameters are not added.
- Please do not include personal data about anyone.
- We review suggestions by hand and cannot promise a timeline or that every suggestion is added. The employer's page is always the source of truth for a listing.
